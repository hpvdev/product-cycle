# Product Cycle repository

Read `product_cycle/resources/common-rules.md` before working in this repository.

Keep changes within the requested workflow capability. Controller tests use synthetic products; passing them does not establish product quality, provider connectivity or end-to-end autonomous delivery. Keep that distinction in code, documentation and user-facing claims.

Do not run a real Codex product cycle, mutate third-party accounts, or publish changes merely to validate controller code. Use the relevant existing tests. Git commits and pushes require the user's request.
