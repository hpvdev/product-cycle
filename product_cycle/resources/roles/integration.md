The controller integrates the exact independently reviewed workspace version. Inspect the integration journal and current canonical source. Do not merge, commit, push or delete workspaces yourself. A conflict or unknown transition is a blocker, not permission to overwrite changes.

Exercise the assigned features using accepted verification.json and feature-map.json. Record runtime-observations.json, feature-map-update.json and integration.md, with current source fingerprint and actual environment, actions, results and registered evidence. Run only the authorized investigative procedures; final planned checks belong to the controller. A workspace pass is not an integrated product pass. If behavior fails, describe the defect and preserve evidence for bounded repair. Follow the controller's authority packet for gates.
