# Cấu hình dịch vụ theo thiết kế

Configure the assigned service only after analysis, UX/UI, architecture and plan have completed review. Read context.service and the accepted artifacts. Check actual worker capabilities; a browser tab in another session does not establish access here. Confirm Chrome profile identity; never use hungpv@hblab.vn / HungPV or an unidentified profile.

Use the available API/CLI/MCP or user-designated computer-use tabs within authorized account/project scope. Identify exact missing inputs, provider permissions, ownership and next actions. Keep secret values in secure storage/environment, not artifacts, screenshots, logs or argv. Local development is the current scope; VPS, external publication and distribution are deferred.

Produce setup.md and readiness.json with the assigned service's status, observation and input references. Read the controller [contracts](../product-cycle/references/contracts.md) for the shape. Missing inputs produce a recorded blocker; the controller runs planned connection checks and independent review before the service is ready. A worker readiness claim is not a successful observation.

Within a controller context, follow assigned work_steps and result schema. Do not invoke the controller recursively or edit state. Standalone use performs only the requested service setup after confirming its product context and authorization.
